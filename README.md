# 수학 튜터 (MathTutor)

Claude AI가 1:1로 대학 수학을 가르쳐 주는 Windows 데스크톱 앱입니다. 개인이 만든 무료 앱이에요.

- **7과목**: 미적분학, 다변수 미적분학, 선형대수학, 미분방정식, 공업수학, 확률과 통계, 이산수학 (MIT OCW 목차를 참고한 진도표)
- **교과서처럼 깊은 설명**: 한 번에 / 단계별(진행 막대) 모드, 판서식 그림과 정확한 그래프(2D/3D)
- **검산**: 튜터의 어려운 계산과 문제의 정답을 앱이 SymPy로 직접 확인하고, 내 답도 수식으로 채점해요
- **복습**: 주제별 간격 반복, 오답노트(변형 문제), 시험 모드(범위·문항 수·난이도·시간)
- **부분 집어서 묻기**: 설명의 문단이나 드래그한 부분만 골라 "다시 / 더 쉽게 / 예시로" 물어보기
- **구글 계정 동기화(선택)**: 여러 PC에서 진도와 대화를 이어 가기

## 받기

**[최신 버전 내려받기 (MathTutor.exe)](https://github.com/Leopard7711/MathTutor-releases/releases/latest/download/MathTutor.exe)**

- Windows 10/11 (64비트). 설치 없이 exe 하나로 실행돼요.
- 새 버전이 나오면 앱이 켜질 때 알아서 업데이트해요.
- **이 페이지(github.com/Leopard7711/MathTutor-releases)에서만 받으세요.** 다른 곳에 올라온 파일은 변조됐을 수 있어요.

### "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없는 개인 앱이라 처음 실행할 때 Windows가 경고를 띄워요.
**추가 정보** → **실행**을 누르면 됩니다. 백신이 막으면 이 페이지에서 받은 파일인지 확인한 뒤 예외로 허용해 주세요.

## 처음 시작: Anthropic API 키 넣기

이 앱은 AI 사용료를 **본인의 Anthropic 계정에서 직접** 내는 방식이에요(개발자에게 가는 돈은 없어요).

1. https://console.anthropic.com 에 가입합니다.
2. **Billing**에서 결제 수단을 등록하고 크레딧을 충전합니다.
3. **API Keys** → **Create Key**로 키(`sk-ant-…`)를 만들어 복사합니다.
4. 앱을 처음 켜면 나오는 창에 붙여 넣으면 끝. 키는 이 PC에만 저장돼요.

## 비용은 얼마나?

앱 아래 상태줄에 이번 세션과 누적 비용(추정)이 늘 표시돼요. 설정에서 모델을 바꿀 수 있어요.

| 모델 | 특징 | 대략적인 비용 |
|---|---|---|
| Opus (기본) | 가장 깊고 정확한 설명 | 공부 1시간에 약 $3 |
| Sonnet | 일반 개념 설명과 문제 풀이는 충분 | 약 절반 |
| Haiku | 복습·연습·짧은 질문용 | 훨씬 저렴 |

실제 비용은 질문 길이와 양에 따라 달라요. 설정의 "비용 절약 모드"를 켜면 채점·힌트처럼 단순한 단계의 비용이 줄어요.
