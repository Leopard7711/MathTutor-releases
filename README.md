# 수학 튜터 (MathTutor)

Claude AI가 1:1로 대학 수학을 가르쳐 주는 Windows 데스크톱 앱입니다(안드로이드 폰 앱도 있어요). 개인이 만든 무료 앱이에요.

- **7과목**: 미적분학, 다변수 미적분학, 선형대수학, 미분방정식, 공업수학, 확률과 통계, 이산수학 (MIT OCW 목차를 참고한 진도표)
- **교과서처럼 깊은 설명**: 한 번에 / 단계별(진행 막대, '다음 ▶') 모드, 판서식 그림과 정확한 그래프(2D/3D). 예제의 풀이는 접혀 있어서 먼저 풀어 본 뒤 펼쳐 볼 수 있어요
- **설명 검토**: 긴 개념 설명은 보여 주기 전에 다른 AI가 한 번 더 읽고, 틀린 문장이나 빠진 조건을 고쳐서 보여 줘요
- **공식집**: 한 번 증명한 공식과 정리한 개념을 저장해 두고 다시 꺼내 써요(검증됨 표시). 공식을 누르면 그 공식의 증명이 펼쳐져요.
  증명은 **꼭 알아야 해요 / 알면 좋아요 / 몰라도 돼요**로 나눠 꼭 필요한 것만 펼쳐 보여 주고, 과정과 상관없는 질문은 '과정 밖 질문'에 따로 모아요
- **검산**: 튜터의 어려운 계산과 문제의 정답을 앱이 SymPy로 직접 확인하고, 내 답도 수식으로 채점해요
- **사진으로 묻기**: 📷 버튼이나 붙여 넣기(Ctrl+V)로 문제·손으로 쓴 풀이 사진을 보내면 읽고 어디서 틀렸는지 짚어 줘요
- **복습**: 주제별 간격 반복, 오답노트(변형 문제), 시험 모드(범위·문항 수·난이도·시간)
- **부분 집어서 묻기**: 설명의 문단이나 드래그한 부분만 골라 "다시 / 더 쉽게 / 예시로" 물어보기
- **구글 계정 동기화(선택)**: 여러 PC와 폰에서 진도와 대화를 이어 가기

## 받기

**[최신 버전 내려받기 (MathTutor.exe)](https://github.com/Leopard7711/MathTutor-releases/releases/latest/download/MathTutor.exe)**

- Windows 10/11 (64비트). 설치 없이 exe 하나로 실행돼요.
- 새 버전이 나오면 앱이 켜질 때 알아서 업데이트해요.
- **이 페이지(github.com/Leopard7711/MathTutor-releases)에서만 받으세요.** 다른 곳에 올라온 파일은 변조됐을 수 있어요.

### "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없는 개인 앱이라 처음 실행할 때 Windows가 경고를 띄워요.
**추가 정보** → **실행**을 누르면 됩니다. 백신이 막으면 이 페이지에서 받은 파일인지 확인한 뒤 예외로 허용해 주세요.

### 안드로이드 폰 앱

[Releases](https://github.com/Leopard7711/MathTutor-releases/releases)에서 `MathTutor.apk`가 함께 올라간 가장 최근 버전을 폰으로 받아 설치하세요.
플레이스토어 앱이 아니라서 처음에 "출처를 알 수 없는 앱 설치"를 허용해야 하고, Play 프로텍트가 경고하면 **무시하고 설치**를 누르면 돼요.
그다음부터는 앱이 새 버전을 알려 주고, **업데이트**만 누르면 돼요. 같은 구글 계정으로 로그인하면 PC와 기록이 이어져요.

## 처음 시작: API 키 넣기

이 앱은 AI 사용료를 **본인의 Anthropic(Claude) 또는 OpenAI(GPT) 계정에서 직접** 내는 방식이에요(개발자에게 가는 돈은 없어요).

- **Claude (기본)**: https://console.anthropic.com 가입 → **Billing**에서 크레딧 충전 → **API Keys** → **Create Key**로 키(`sk-ant-…`)를 만들어 복사
- **GPT**: https://platform.openai.com 가입 → 결제 등록·크레딧 충전 → **API keys**에서 키(`sk-…`)를 만들어 복사

앱을 처음 켜면 나오는 창에 붙여 넣으면 끝. 어느 회사 키인지는 앱이 알아봐요. 키는 이 PC에만 저장되고 동기화하지 않아요.

## 비용은 얼마나?

앱 아래 상태줄에 이번 세션과 누적 비용(추정)이 늘 표시돼요. 설정에서 모델을 바꿀 수 있어요.

| 모델 | 특징 | 대략적인 비용 |
|---|---|---|
| Claude Opus (기본) | 가장 깊고 정확한 설명 | 공부 1시간에 약 $2~3 |
| Claude Sonnet | 일반 개념 설명과 문제 풀이는 충분 | 약 절반 |
| Claude Haiku | 복습·연습·짧은 질문용 | 훨씬 저렴 |
| GPT-6.1 Sol / Terra | OpenAI 키로 쓰는 중간·저가 모델 | Sonnet보다 조금 싸거나(Sol) 절반(Terra) |

실제 비용은 질문 길이와 양에 따라 달라요. 설정의 "비용 절약 모드"를 켜면 채점·힌트처럼 단순한 단계의 비용이 줄어요.
긴 대화를 오래 쉬었다가 이어 가면 첫 답이 비싸지는데, 그럴 땐 앱이 "새로 시작 / 이어 가기"를 먼저 물어봐요.
새로 시작할 때 "지난 대화 이어서"를 고르면 지난 대화를 짧게 요약해 넘겨서(약 1센트) 하던 데부터 이어 가요.
